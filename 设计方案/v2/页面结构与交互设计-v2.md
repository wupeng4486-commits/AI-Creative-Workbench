## 整体结构保持不变

左侧导航固定为：首页总览、智能体、创作工作室、资产库、连接器、技能、工作流、数据与设置。

顶部保留全局搜索与本地演示标识。一级模块使用相同的导航与基础组件，各自的内容布局按实际工作设计。

新增能力安放在现有模块中：

| 内容 | 所在位置 | 与其他模块的关系 |
| --- | --- | --- |
| Agent 专业角色、资料范围、案例学习与评估 | 智能体详情 | 引用资产库案例、技能评分标准及连接器工具 |
| 商品知识、原始素材、优秀案例与反例 | 资产库 | 作为 Agent、技能和工作流共同使用的资料来源 |
| 分析方法、评分标准、镜头规范、质检规则 | 技能 | 一份规则可被多个智能体和工作流引用 |
| AI 视频、AI 图片、美工、剪辑的制作草稿与成果 | 创作工作室 | 选择智能体、技能和流程，归档到资产库 |
| LibTV、视频分析、图像生成、剪辑、质检工具入口 | 连接器与集成配置 | 第一版保存接口位置和演示配置，后续连接真实工具 |
| 稳定的制作顺序、参数与输入输出 | 工作流 | 可以选择 LibTV 托管或平台分步控制 |
| 版本、评估记录、备份与恢复 | 对应模块与数据设置 | 记录来源，保留历史，统一备份 |

不增加第九个“训练中心”，也不把智能体、技能和工作流合并为同一种对象。

### 详情中的案例学习与评估

![智能体案例学习与评估](E:/AI%20Creative%20Workbench/设计方案/v2/09-智能体-案例学习与评估.png)

保留角色配置、指令、关联技能与演示对话，新增“案例与知识”“评分标准”“工具与技能”“评估与反馈”页签。

案例与知识：

- 选择本 Agent 可引用的商品知识和案例集，包含优秀案例、反例及待整理案例。
- 选择范围表示 Demo 的检索范围，不表示实现了多人权限。以后局域网版按真实资料权限过滤。
- 上传到案例集后进入“待标注”，可以标记时间段、关键帧、视频类型、开场、产品露出、使用动作、结尾结构和优缺点。
- “模拟分析”展示视频拆解与建议样例；用户标注与演示分析分开保存。
- 找不到足够案例时，提示补充资料，不伪造来源。

分析建议采用固定格式：任务理解、相似案例与来源、片段时间点、可复用框架、评分依据、问题、改进建议、需要补充的信息。

评分标准：

- 引用技能中的评分规则，避免在每个 Agent 中复制一套。
- 可配置的候选维度包含商品信息准确度、画面与包装一致性、人物及动作完整性、叙事清晰度、剪辑节奏、渠道适配。
- AI 图片、AI 视频、真人剪辑使用适合各自场景的标准，不强行套用同一张评分表。
- 初始标准标为“草稿”。权重、通过线与优秀案例由团队设置，不把设计稿中的样例当作正式标准。
- 人工评分、模拟评分、后续工具评分分别标注来源；每个结果记录使用的标准版本。

评估与反馈：

- 展示问题、原建议、人工修订、采纳原因及关联案例。
- 将改进整理为“待确认建议”，用户可以应用到指令、技能、案例标注或工作流，形成新版本。
- 使用另一批未参与规则整理的案例进行对比评估；未配置评估集时不显示真实通过率。
- 对比行为方案的新旧版本，确认后使用新版本，保留回退入口与历史结果。

### 对“训练、自我迭代与强化学习”的产品表达

把用户提出的长期目标保留为三个阶段，并在界面中分开表示：

| 阶段 | 产品表现 | 第一版范围 |
| --- | --- | --- |
| 企业知识与案例沉淀 | 整理资料、相似案例、固定输出、评分标准与反例 | 本地管理与模拟分析 |
| 反馈驱动的持续改进 | 收集人工修订，形成新指令、新技能、新案例与评估记录 | 管理记录、版本与模拟对比 |
| 专项模型训练或强化学习 | 使用高质量标注数据，连接真实训练与评估服务 | 后续单独规划，不显示为已训练完成 |

后续的市场案例学习路径为：配置来源 → 收集候选案例 → 审核与标注 → 提炼候选方法 → 评估 → 应用到企业规则。第一版支持手动导入案例或登记来源，不自动抓取网站或自动改写生产规则。

智能体与技能按当前类型推荐，但用户可调整。右侧资源区可切换商品知识、素材、相似案例、已选内容。

底部保留保存草稿、模拟制作、停止、归档、另存为流程。每次模拟保留输入快照与运行记录；已有草稿时，新带入资料可以选择加入当前草稿或另建草稿。

### 真人贴片 UGC 剪辑子场景

![真人 UGC 剪辑](E:/AI%20Creative%20Workbench/设计方案/v2/10-创作工作室-真人UGC剪辑.png)

- 使用“缺少所需动作片段”提示补充素材，不把不存在的动作当作已经拍到。

## 工作流

![工作流详情](E:/AI%20Creative%20Workbench/设计方案/v2/07-工作流.png)

### 两种执行方式

| 方式 | 平台能控制的内容 | 流程预览表现 |
| --- | --- | --- |
| LibTV 托管 | 需求、素材、所用内置能力、总体参数、结果回收 | 展示发送资料、等待结果、回收与检查；不虚构 LibTV 内部节点进度 |
| 平台分步 | 每一步的输入、所用技能或工具、参数、输出及失败处理 | 展示明确节点与依赖；后续通过已确认的 lib-cli 接口调用 |

第一版均为模拟。托管方式与分步方式分别保存参数，不因切换方式而悄悄丢失配置。

### 四个复用模板

| 模板 | 输入 | 步骤与参数重点 | 输出与检查 |
| --- | --- | --- | --- |
| 人物贴贴片｜真人 UGC 剪辑 | 真人实拍视频、商品资料、文案与输出要求 | 标记手持和贴敷片段 → 筛选排序 → 剪辑整理 → 字幕声音 → 质检；参数包含片段范围、时长与比例 | 剪辑方案、片段表、成片示例；检查动作、人物和商品一致性 |
| 人物产品展示 | 人物素材、商品图或视频、展示要求 | 在模板中明确选择已有素材剪辑或 AI 制作，再显示匹配的节点与参数 | 人物产品展示示例与来源；检查包装、画面与展示完整性 |
| 批量替换产品包装 | 原素材、新包装素材、对应关系表 | 选择图片或视频任务 → 包装匹配 → 替换任务 → 逐项检查；不假定两类素材用相同操作 | 每项结果、前后对比、未完成与异常项 |
| 视频批量去字幕 | 多个视频、字幕区域或处理要求、输出规格 | 文件检查 → 字幕处理任务 → 逐项预览 → 批量交付；保留音轨等要求单独设置 | 每个视频的状态、处理区域预览、异常与重试记录 |

批量任务可以查看每项输入、输出、问题与重试，不以一条“全部成功”遮盖部分失败。

第一版步骤通过表单添加、删除和排序，不制作完整拖拽编辑器。原始 LibTV 文件可作为附件保存，不承诺解析尚未确认格式的原生文件。

## 完整内容闭环

商品知识与原始素材 → 案例整理与标注 → 技能与评分标准 → 专业 Agent 引用 → 工作室制作 → 质检与人工反馈 → 成果归档与流程复用 → 更新案例、技能和行为方案 → 再次评估。

每个结果记录商品、素材、案例、Agent、技能版本、流程与参数来源。人工反馈先成为待确认的修改建议，应用后形成新版本；历史结果保留当时的来源快照。

相同案例、技能与素材以关联方式复用，避免多个模块各存一份后互相不一致。

## 状态与保存规则

- 智能体：草稿、可使用；资料与案例状态另列待整理、待标注、可引用，不展示虚假的模型训练进度。
- 模拟分析与制作：等待、演示中、完成、失败、已停止；图片、视频、评分结果标明示例来源。
- 编辑时明确保存，工作室草稿自动保存；保存成功才显示已保存到本机。
- 未保存离开时提供保存、放弃、继续编辑；导入失败、空间不足、无法预览等状态保留重试或下载入口。
- 被引用资料删除前提示影响，需先解除使用关系；历史快照仍保留。
- 恢复备份前先检查完整性并展示替换范围，校验失败不修改现有数据。

## 设计验收路径

- AI 视频：选择广告导演与商品知识 → 引用相似案例 → 查看分镜示例 → 模拟制作 → 归档。
- AI 图片：选择视觉顾问与参考图 → 整理构图与提示词 → 对比候选示例 → 记录反馈。
- 传统美工：创建交付要求 → 关联素材 → 保存源文件与交付预览 → 归档设计成果。
- 真人贴片 UGC：导入真实片段 → 标记手持与贴敷动作 → 查看剪辑结构 → 模拟质检 → 归档。
- Agent 改进：从案例整理与人工评分开始 → 形成规则修改建议 → 保存新版本 → 用独立案例做模拟对比。
- 稳定工作流：从模板选择执行方式 → 检查输入和参数 → 模拟节点状态 → 回看输入输出与异常记录。
- 本地持续使用：关闭重开后，资料、原文件、草稿、标注、参数与历史仍能恢复。
