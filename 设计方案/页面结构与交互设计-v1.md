阶段：页面结构与交互设计  
交付：8 张静态页面结构稿、页面说明、关键交互与验收场景。尚未创建应用项目或实现应用功能。

[查看八个页面的结构总览](E:/AI%20Creative%20Workbench/设计方案/00-八个页面结构总览.png)

## 1. 设计前提

- 使用者是运营与设计团队。第一版在单台电脑浏览器中运行，后续再面向约 20–30 人的公司局域网使用。
- 界面使用中文，优先照顾桌面浏览器。建议以 1440 像素及以上窗口展示；较窄的桌面窗口可折叠侧栏，不设计手机端。
- 本地保存商品资料、素材文件、智能体、技能、工作流、配置和操作记录。刷新、关闭、重启后保留。
- 第一版无需应用登录。“我创建的”“团队共享的”表示 Demo 中的内容来源，不代表真实权限控制。
- 智能体对话、内容制作、连接器连接与同步、工作流执行均为模拟，并在相关位置注明。
- libtv 仅保留接口和配置位置。NAS 提供实际访问入口，不自动扫描或同步文件。
- 图中的名称、数字、成员和文件均为示例，实际首页数字应从当前本地记录统计。

## 2. 整体页面结构

左侧固定保留八个一级入口，顺序与确认的需求一致：

1. 首页总览
2. 智能体
3. 创作工作室
4. 资产库
5. 连接器
6. 技能
7. 工作流
8. 数据与设置

顶部提供全局搜索、本地演示标识与保存状态。内容区展示当前模块的标题、说明及主要操作；不设置无实际作用的公司切换器、在线成员或权限入口。

全局搜索按“智能体 / 技能 / 资产 / 工作流”分组返回本地结果，点击后打开对应详情，并保留返回来源。模块自身的搜索和筛选仅作用于当前模块。

公共交互规则：

- 查看一条资料：优先打开右侧详情面板，关闭后保留原有筛选和滚动位置。
- 编辑短表单：使用侧面板；商品知识、技能正文等长内容使用宽面板；创作与流程预览使用主内容区域。
- 新建和编辑：提供明确的“保存”和“取消”，保存成功后才提示“已保存到本机”。
- 工作室草稿：自动保存，显示“保存中 / 已保存 / 保存失败”。保存失败时保留当前输入，并提供重试与备份入口。
- 存在未保存修改时离开：提供“保存后离开 / 放弃修改 / 继续编辑”。
- 删除：说明对象名称及影响。仍被引用的资料需先解除引用；历史创作成果和历史运行快照保留。
- 内容状态与演示状态分别表达，例如“草稿 / 可使用”和“模拟运行完成”。颜色之外同时显示文字。

## 3. 首页总览

![首页结构稿](E:/AI%20Creative%20Workbench/设计方案/01-首页总览.png)

首页回答三个问题：团队有哪些可复用内容、最近发生了什么、现在可以从哪里开始。

页面从上至下：

1. 标题与说明，右侧主要操作为“开始创作”。
2. 四张数量卡：团队智能体、团队技能、共享文件、团队工作流。点击卡片进入相应模块，并应用团队共享筛选。
3. 左侧主区域“团队共享”，按全部、智能体、技能、文件、工作流筛选。每条内容显示类型、名称、用途、来源和更新时间。
4. 右侧“快捷操作”：开始创作、新建智能体、新建技能、导入文件；下方展示最近使用。
5. 下方展示动态：本机新建、修改、归档和模拟运行记录。初始成员活动标明“示例”，本机操作以“本机用户”记录。

共享内容卡上的操作随类型变化：智能体是“去创作”，技能是“查看技能”，文件是“预览”，工作流是“预览流程”。不把所有内容都做成同一种待办任务。

## 4. 智能体

![智能体结构稿](E:/AI%20Creative%20Workbench/设计方案/02-智能体.png)

页面使用智能体卡片，顶部提供搜索、来源筛选、用途标签，以及“新建智能体”。来源包含全部、我创建的、团队共享的。

每张卡片显示名称、用途说明、来源、技能数量、知识资料数量及更新时间。主要操作为“去创作”，次要操作为“查看详情”；复制与删除放在更多菜单。

详情面板包括：

- 概览：名称、用途、标签、来源和更新时间。
- 行为指令：角色、输出要求和限制。
- 知识与技能：关联已有商品知识、资料和技能，支持查看原资料。
- 演示对话：预设问题与示例回复，持续显示“示例回复，未调用模型”。

新建需要名称和用途；指令、标签、关联资料可稍后补充。“去创作”将智能体带入工作室，不自动开始演示。团队示例内容可复制为自己的版本后修改。

## 5. 创作工作室

![创作工作室结构稿](E:/AI%20Creative%20Workbench/设计方案/03-创作工作室.png)

页面围绕一份创作草稿组织，而非使用通用任务表。顶部显示可编辑的创作标题、保存状态和历史版本入口。

三栏结构：

- 左栏“创作要求”：内容用途、目标渠道、商品知识、智能体、技能、补充要求。
- 中栏“制作与预览”：空白引导、模拟制作进度、示例成果和成果操作。可以切换文案、图片或视频示例预览。
- 右栏“参考素材”：搜索本地素材、预览、添加到本次创作；同时显示已选素材及移除操作。

完整操作流程：

1. 选择商品知识与内容用途，填写创作要求；必填缺失时在字段旁提示。
2. 选择智能体和技能，可以沿用从其他模块带入的选择。
3. 添加参考素材；NAS 路径作为引用，不把该路径当作已经读取的文件。
4. 点击“开始演示”，依次显示整理资料、组合内容、制作示例、完成预览。页面持续标注“模拟制作”。
5. 演示进行时可以停止；停止后保留草稿，不产生一份已完成成果。
6. 完成后可修改要求并再次演示，旧结果保留在历史中。
7. 点击“归档到资产库”，补充名称、分类和标签，保存示例成果及关联来源。重复点击不重复创建同一归档。
8. 点击“另存为流程草稿”，把当前选择和制作步骤保存到工作流，明确标注尚未连接 libtv。

运行前冻结本次输入快照；演示进行时继续修改的内容只影响下一次运行。历史详情可回看当时使用的商品知识、技能和素材。

libtv 在第一版仅显示“接口预留，尚未接入”，不提供会让人误以为正在真实制作的连接成功提示。

## 6. 资产库

![资产库结构稿](E:/AI%20Creative%20Workbench/设计方案/04-资产库.png)

按资料的用途组织四个子页：商品知识、共享文件、图片与视频、NAS 入口。保留搜索、标签筛选与来源筛选；媒体适合缩略图，资料适合表格。

商品知识：

- 维护商品名称、货号、简介、核心卖点、注意事项与关联素材。
- 详情展示关联智能体、工作流及近期创作记录。
- “用于创作”打开工作室并带入这份商品知识。

文件与媒体：

- 支持本地导入，显示导入进度和失败原因；成功保存原文件后才显示导入成功。
- 图片、常见音视频、PDF 和纯文本在浏览器支持时预览；其他格式显示资料信息与下载入口。
- 文件详情包括名称、类型、标签、来源、备注与关联创作。
- “用于创作”将资料加入工作室的已选素材。

NAS 入口：

- 维护入口名称、地址类型、地址和备注。
- 网页地址以新标签页打开；Windows 共享路径或网络盘路径提供复制操作，引导在文件资源管理器访问。
- Windows 路径不设计成承诺一定能在浏览器里打开的按钮。
- NAS 中的文件可手动登记为引用记录，但不显示为“已存入本机”，不自动扫描目录。

创作成果在此保留来源关系：使用的商品知识、智能体、技能、工作流与草稿。复制路径和打开网页均不等于将 NAS 文件导入本地。

## 7. 连接器

![连接器结构稿](E:/AI%20Creative%20Workbench/设计方案/05-连接器.png)

页面采用“连接器目录 + 配置详情”的结构。目录可按电商、邮件、研发等分类，展示 Shopify、Gmail、GitHub 等示例。

顶部“添加连接器”从目录选择服务，并新建一份演示连接；卡片展示已添加的连接。

每个连接器显示用途、配置状态、最近模拟同步时间及操作。详情包含配置、可同步内容说明和模拟记录。

交互：

1. 点击“配置演示”，填写连接名称及示例同步范围；第一版不索取真实账号授权或真实密钥。
2. 保存后显示“已配置，待模拟连接”。
3. 点击“模拟连接”，显示模拟成功或可重试的失败状态。
4. 模拟连接成功后可“模拟同步”，展示示例数量、耗时和日志。
5. 模拟同步默认只产生示例结果与日志，不悄悄修改资产库。需要保留时，单独点击“将示例导入资产库”。
6. 停用后不可继续模拟同步，已有配置与记录保留。

状态文字统一为未配置、待模拟连接、模拟连接成功、模拟连接失败、已停用，避免使用可能被理解为真实授权成功的“已连接”。

## 8. 技能

![技能结构稿](E:/AI%20Creative%20Workbench/设计方案/06-技能.png)

使用“技能目录 + 正文详情”的布局，方便阅读长指令。顶部支持搜索、场景标签、来源筛选和新建。

目录显示技能名称、适用场景、来源、更新时间与引用数量。正文按四部分组织：

- 适用场景：解决什么问题，适合哪些内容。
- 输入与输出：需要准备哪些资料，应该得到什么结果。
- 步骤与指令：可编辑的工作步骤、检查要求和输出格式。
- 示例与引用：输入输出示例，关联的智能体和工作流。

新建技能提供空白表单和少量示例结构；支持保存草稿、编辑、复制与删除。可以将技能关联已有智能体，或带入工作室。这里存放可复用的方法，演示对话仍放在智能体中。

## 9. 工作流

![工作流结构稿](E:/AI%20Creative%20Workbench/设计方案/07-工作流.png)

顶部选择工作流并展示用途和状态。主体分为流程预览区、步骤详情区，下方提供模拟运行记录。

- 流程节点按步骤关系展示，例如准备商品知识 → 提炼卖点 → 生成图文示例 → 归档成果。
- 点击节点，右侧展示输入、输出、使用的技能、关联素材与说明。
- “编辑步骤”打开结构化表单，支持新增、删除和调整顺序；第一版不做复杂的拖拽编排器。
- 支持从空白草稿新建、复制既有流程，以及从工作室保存流程草稿。
- “去工作室使用”将流程要求和关联内容带入工作室，等待用户确认后开始演示。
- “模拟运行”显示各步骤状态，并产生一条可回看的模拟运行记录。
- libtv 原始文件可作为流程附件保存和下载；未确认原生格式前，不承诺解析任意 libtv 文件。

步骤状态包括等待、模拟运行中、完成、失败、已停止。失败记录保留原因与当时输入，重试会产生新记录。

## 10. 数据与设置

![数据与设置结构稿](E:/AI%20Creative%20Workbench/设计方案/08-数据与设置.png)

作为本地后台，包含数据概况、备份与恢复、集成配置、显示偏好四组设置。

- 数据概况：各类型记录数、文件数量、本机存储用量与最近备份时间。
- 备份：导出完整备份，包含资料、素材原文件、配置和历史记录，并显示完成或失败。
- 恢复：先检查文件是否有效，显示备份时间与各类数量，说明会替换哪些本地数据；确认后恢复。校验失败不修改现有数据。
- 集成配置：管理同一份 NAS 入口和 libtv 预留设置，从资产库编辑的入口也在这里更新。
- 显示偏好：列表或网格默认视图、侧栏收起状态等少量实用设置。
- 示例内容：可以补充缺失的示例内容，不覆盖用户修改；清空全部数据另行确认，并提示先备份。

不添加成员管理、角色权限、登录方式、云端计费等第一版范围以外的后台菜单。

## 11. 跨模块联动

| 起点 | 用户操作 | 到达与结果 |
| --- | --- | --- |
| 首页共享内容 | 打开某个智能体 | 智能体详情，保留来源与返回位置 |
| 智能体 | 去创作 | 工作室预选智能体及其默认关联项，允许调整 |
| 商品知识 / 素材 | 用于创作 | 工作室带入对应资料，原记录不重复创建 |
| 技能 | 添加到智能体 / 用于创作 | 选择目标或打开带入该技能的工作室草稿 |
| 工作流 | 去工作室使用 | 工作室创建带有流程来源的草稿 |
| 工作室 | 归档成果 | 资产库新增成果，保留制作来源；首页更新数量与动态 |
| 工作室 | 另存为流程草稿 | 工作流新增可预览、可编辑的草稿 |
| 连接器 | 将示例导入资产库 | 资产库新增明确标为示例的资料，避免重复导入 |
| 任一资料 | 修改或删除 | 相关引用、数量与首页动态同步更新 |

工作室已经有草稿时，从其他模块带入内容应让用户选择“加入当前草稿”或“新建草稿”，不直接覆盖已有输入。

## 12. 空内容、异常与保存

| 场景 | 界面反馈与可执行操作 |
| --- | --- |
| 首次进入 | 载入示例，说明是本地演示；不反复弹出引导 |
| 当前模块没有内容 | 说明可以存放什么，提供与模块匹配的新建或导入入口 |
| 搜索没有结果 | 保留搜索词，提供清除筛选和相关新建操作 |
| 表单缺少必要信息 | 在字段附近提示，保留其他已填内容 |
| 文件无法预览 | 显示文件信息与下载，不出现无解释的空白区域 |
| 文件导入或保存失败 | 说明失败，保留可重试的输入，不显示成功状态 |
| 空间不足 | 停止写入，提示备份与清理；不自动删除旧数据 |
| NAS 无法访问 | 保留地址和复制操作；由外部页面展示实际连接结果，不伪造访问成功 |
| 模拟运行失败或停止 | 保留草稿与日志，允许修改后重新演示 |
| 备份文件损坏 | 指出文件无法恢复，现有数据保持不变 |
| 引用的资料缺失 | 明确标注缺失项，提供重新选择，不偷偷换成其他资料 |

## 13. 视觉方向

- 采用清晰、克制的桌面工作台风格：浅灰背景、白色内容面板、深色正文和少量蓝色操作强调。
- 页面标题、操作、正文和辅助信息有明确层级。避免大面积装饰、营销文案和无数据依据的效率指标。
- 首页重信息概览，工作室重内容预览，资产库重素材，技能重阅读，工作流重步骤关系。
- 卡片适合智能体和媒体；列表适合共享文件；技能使用阅读布局；连接器使用配置布局。
- 按钮文案表达具体动作，例如“归档到资产库”“预览流程”“模拟同步”，不用泛化的“执行任务”。
- 这轮图片是静态结构稿，说明布局与信息层级，不代表已经实现交互。示例图片用占位内容表达。

## 14. 进入开发前的设计验收场景

使用“轻行随行杯新品图文”作为统一示例：

1. 在首页找到共享的电商内容助手，查看其知识和技能。
2. 点击去创作，进入已选该智能体的工作室。
3. 选择商品知识和两份参考素材，填写渠道与创作要求。
4. 演示制作并查看文案与视觉示例，明确看到模拟标识。
5. 将成果归档，在资产库查看成果及其来源。
6. 将制作方法保存为流程草稿，在工作流中预览步骤。
7. 返回首页，看到更新后的数量和本机操作动态。
8. 关闭并重新打开应用，资料、草稿、配置和记录仍然存在。
9. 导出备份，确认恢复预览与错误文件提示的设计路径完整。

本轮完成到页面与交互方案，不自动进入项目创建、应用开发、真实服务接入或部署。
